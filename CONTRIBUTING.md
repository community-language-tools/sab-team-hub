# Contributing

Thank you for looking at this project.

## Maintenance status

This project is maintained alongside other work. Issues and feedback are very welcome.
Pull requests may be reviewed slowly — please **open an issue first** so we can discuss
whether an approach is likely to be accepted before you spend time on it.

## Reporting a problem

Open an issue describing what you did, what you expected, and what happened instead. You
do not need to be a programmer for this to be useful. Reports of unclear documentation are
just as valuable as bug reports.

Please do not include real team member names, real project data, or file paths containing
personal information in an issue.

## Pull requests

- Open an issue first for anything beyond a typo.
- Keep changes small and focused — one concern per pull request.
- Never commit real configuration (`config/team.json`, `config/users.json`,
  `config/projects.json`) or any real project data.
- Run the tests before opening the PR.
- Describe the change in plain language: what the problem was, what you changed, and how a
  reviewer can verify it works.

## Language

Code, comments, documentation and pull request descriptions are in English.

User-facing text in the application itself is translated — see `languages/`. Contributions
of translations are welcome.
